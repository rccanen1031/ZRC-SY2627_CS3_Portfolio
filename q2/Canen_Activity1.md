1. What is/are the parent class/es of the Programmer class in the video?
   Ans:The main parent class of Programmer is Employee. But since Employee inherits from Person, Person is also like an ancestor/parent class to it.

2. If you were to add a new role called Intern, where would you place it in the inheritance
hierarchy? Why?
   Ans: The Intern class should be placed as a child class (subclass) inheriting directly from the Employee class (or Person class, depending on whether interns are considered paid/formal employees with job details).
